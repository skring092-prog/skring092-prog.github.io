Screenshot comparison

Screenshot comparison submitted in support of an App Review Guideline 4.1 report. The comparison focuses on product structure, functional organization and user flow.

Pilzgebiete on the left · Mykotop on the right. Screenshots are shown unaltered; two earlier Pilzgebiete captures are marked below. On narrow screens, swipe each pair horizontally. Select any screenshot to open its full-resolution image.

1. Area flow 2. Forest map 3. Species 4. Saved areas 5. Premium / Pro

1. Area selection and detail flow

Both selected-area views place a named forest area, a suitability grade, species information and further actions in a sheet over the map.

2. Classified forest-area map

Both maps show coloured forest polygons around Murnau and Ohlstadt with a letter-based suitability legend.

3. Species-specific map functionality

Both interfaces provide named mushroom-species controls for selecting which species the map should represent.

4. Saved areas / personal mushroom locations

Both apps provide a dedicated saved-areas section for keeping forest areas selected from the map.

5. Premium / Pro model

Both personal sections present a named upgrade tier with feature benefits, with Mykotop's Pro tier marked “Coming Soon”.
